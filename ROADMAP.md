# Roadmap

## Public beta — 20-learner test
- [x] Responsive South Africa-first study workspace.
- [x] Browser-local notebook, subject list and study planner.
- [x] Extractive quick summary, case brief worksheet, flashcards and recall quiz.
- [x] Data export and delete controls.
- [x] Public beta guide and privacy notice.
- [x] AI and server API disabled to avoid unexpected costs and third-party processing.
- [x] Static deployment bundle and security headers.
- [ ] Invite 20 learners and collect voluntary feedback outside the app.
- [ ] Fix usability issues identified during testing.

## Before adding accounts or AI
- [ ] Publish a canonical public source repository and contribution workflow.
- [ ] Perform a POPIA/privacy review, including children's information and any cross-border processing.
- [ ] Decide whether student accounts and cloud sync are genuinely needed; define deletion/export and retention first.
- [ ] Build a provider-independent AI adapter with no browser-side keys.
- [ ] Implement prepaid/usage ceilings, per-user budgets, global kill switch and cost monitoring before opening AI access.
- [ ] Secure rights for every legal-source connector and automated use. Do not ingest SAFLII content for RAG, embeddings, training or automated research without written permission.
- [ ] Build source provenance and legislation version/currentness records.
- [ ] Add case citation/paragraph verification against permitted primary sources.
- [ ] Create a South African law evaluation set reviewed by qualified legal educators/practitioners.
- [ ] Red-team prompt injection, unsafe uploads, wrong jurisdiction and unsupported legal questions.

## Future expansion
- [ ] PDF text extraction with page-level references and clear handling of scanned PDFs.
- [ ] Spaced repetition and richer quizzes.
- [ ] Human-reviewed multilingual glossary and interface translation.
- [ ] Community resource submissions with moderation and licence review.
- [ ] Additional jurisdictions only with separate source sets, jurisdiction metadata and reviewers.
- [ ] Consider self-hosted/open-weight models after comparing accuracy, operating costs and privacy.
